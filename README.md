# STM32 两轮自平衡小车

基于 STM32F103 + MPU6050 的两轮自平衡小车，采用倒立摆模型与 PID 三环控制，实现自主站立、前进/后退、原地转向与三档变速，支持 OLED 实时显示与 HC-05 蓝牙上位机控制。

> 本项目为个人出于兴趣独立完成的软硬件实践项目，从需求分析、方案设计、电路搭建到代码调试全程自主完成。

## 项目特性

- **自主站立**：闭环控制下动态平衡，静止姿态保持 ±2° 以内，响应时间 ≤ 50ms
- **运动控制**：前进、后退、原地转向（差速控制），低/中/高三档速度实时切换
- **蓝牙遥控**：HC-05 透传，统一指令格式 `CMD,vel=speed,dir=type`，波特率 115200
- **实时显示**：OLED 显示当前速度、俯仰角度、电池电量（ADC 分压采样计算），刷新率 ≥ 1Hz
- **姿态解算**：MPU6050 内置 DMP 输出四元数，解算俯仰/横滚/偏航角，采样 100Hz

## 硬件清单

| 模块 | 型号 / 规格 |
| --- | --- |
| 主控 | STM32F103C8T6（PWM：TIM3 / 编码器捕获：TIM2 / I2C / UART） |
| 姿态传感器 | MPU6050（I2C，内置 DMP） |
| 电机驱动 | TB6612，双电机独立控制 |
| 电机 | 带编码器直流减速电机，编码器分辨率 ≥ 500 PPR |
| 显示 | 0.96 寸 OLED（SSD1306，128×64，I2C） |
| 通信 | HC-05 蓝牙模块（透传模式，115200） |
| 供电 | 12V 2000mAh 锂电池，100k+10k 分压采样电量 |

## 软件架构

```
Core/Src/
├── main.c            # 主循环与任务调度
├── pt_mpu6050.c      # MPU6050 驱动 + DMP 姿态解算
├── pt_pid.c          # PID 控制器
├── encode.c          # 编码器测速
├── tb6612.c          # 电机驱动（PWM）
├── bt_uart.c         # 蓝牙串口协议解析
├── display.c / oled.c# OLED 显示
└── inv_mpu*.c        # InvenSense 官方运动库
```

控制流程：**姿态采集 → PID 三环（直立环 / 速度环 / 转向环）→ PWM 输出 → 电机执行**，控制周期 10ms，积分项防饱和。

## 编译与烧录

1. 使用 **Keil MDK5** 打开工程：`cubemx_config/MDK-ARM/cubemx_config.uvprojx`
2. 编译（F7），通过 **ST-Link** 下载到板卡
3. 上电后小车自动进入平衡模式；用蓝牙串口助手（115200）发送指令即可遥控

## 蓝牙控制指令

```
CMD,vel=1,dir=1    // 低速前进（三档：1低/2中/3高，对应 PWM 30%/60%/90%）
CMD,vel=1,dir=0    // 后退
CMD,vel=0,dir=2    // 原地转向
```
